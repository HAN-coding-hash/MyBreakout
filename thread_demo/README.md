# 线程与异步加载学习演示

## 文件说明

| 文件 | 说明 |
|------|------|
| 01_thread_basic.exe | 基础线程创建和等待 |
| 02_mutex_demo.exe | 互斥锁保护共享数据，对比有锁/无锁 |
| 03_message_queue.exe | 生产者-消费者模式，条件变量 |
| 04_async_demo.exe | std::async 简化异步任务 |

## 运行方法

在 Windows 命令行或 MSYS2 终端中直接双击或运行对应的 .exe 文件。

## 学习要点

1. **线程 vs 进程**：线程共享内存，进程独立
2. **互斥锁**：避免数据竞争
3. **消息队列**：线程间安全传递数据
4. **std::async**：比手动管理线程更方便
